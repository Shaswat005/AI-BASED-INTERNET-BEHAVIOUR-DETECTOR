AI-BASED INTERNET BEHAVIOUR THREAT DETECTOR
=================================================

1. PROJECT OVERVIEW
-------------------
This project is a cybersecurity tool designed to detect anomalous user behaviour patterns that might indicate a threat (e.g., account compromise, insider threat, or automated attacks). It uses Machine Learning (Isolation Forest) alongside a rule-based system to classify user sessions as "Normal" or "Suspicious".

2. THE ALGORITHM: ISOLATION FOREST
----------------------------------
The core model is the **Isolation Forest** (iForest). 
- **Concept**: Most anomaly detection methods try to define what is "normal" and look for deviations. Isolation Forest does the opposite: it explicitly isolates anomalies.
- **How it works**: 
  1. It builds an ensemble of random decision trees.
  2. For each tree, it randomly selects a feature and a split value.
  3. Anomalies (rare events) are susceptible to isolation and will generally have much shorter paths in the trees (i.e., they are easier to separate from the rest of the data).
  4. Normal points require more splits to be isolated.
- **Why it fits here**: User behaviour data is high-dimensional and complex. iForest is efficient and effective for this type of unsupervised anomaly detection.

3. FEATURE ENGINEERING
----------------------
We process raw logs into meaningful features for the model:

A. Login Time Analysis
   - We convert login times to numeric values (0.0 to 24.0).
   - **odd_hour_login**: Binary flag (1) if login is before 5 AM or after 10 PM.

B. File Activity
   - **sudden_upload_spike**: We calculate the statistical mean and standard deviation of upload counts. If a user's uploads exceed (Mean + 2 * StdDev), it is flagged.

C. IP & Session Data
   - **abnormal_ip_activity**: Flagged if IP changes occur more than twice in a session.
   - **session_duration**: Length of the session in hours.

4. BEHAVIOUR SCORE (RISK SCORING)
---------------------------------
In addition to the ML model, we calculate a deterministic "Behaviour Score" (0-100) to help quantify risk.
Formula:
   Score = 0
   + 20 points if Login is at an Odd Hour
   + 30 points if File Uploads are High
   + 25 points if IP Changes are High
   + 15 points if Failed Logins > 0
   
   The score is capped at 100. This score is also fed into the Isolation Forest model as an input feature.

7. INTERPRETING RESULTS
-----------------------
- **Prediction**: 
  - "Normal": Standard user behaviour.
  - "Suspicious": Behaviour deviates significantly from the cluster of normal users.
